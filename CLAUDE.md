# heidi-content (public)

Public content library + hub for Heidi (hi-heidi.ai). Only FINAL pieces that are meant to be published live here:
`library/<type>/<piece>/<network>/…` with `captions.md`, listed in `library/manifest.json`.
`python3 hub/build_hub.py` regenerates `index.html` (GitHub Pages) and `hub/data.json`.

Everything else (compositors, HyperFrames projects, Heidi references, episode scripts, partner lists, the ElevenLabs relay)
lives in the PRIVATE repo `mycrewai-hub/heidi-studio`. Never commit sources, notes, credentials or unpublished work here.
