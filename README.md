# heidi-content

Public content library and hub for Heidi (hi-heidi.ai): final carousels, videos and captions, per network.

- Hub: https://mycrewai-hub.github.io/heidi-content/ (generated from `library/manifest.json` by `hub/build_hub.py`)
- Library: `library/<type>/<piece>/<network>/…` + `captions.md`

Tooling and sources live in a separate private repository.
